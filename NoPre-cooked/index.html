回锅肉

⚖️材料配比

主料

  • 猪五花肉 500g
  • 豆瓣酱 1大勺

辅料

  • 姜片、蒜瓣适量
  • 青蒜 1根
  • 生抽 1小勺、料酒 1小勺
  • 少许糖

🔪庖厨之术

  1. 将整块五花肉焯水至八成熟，放凉后切成薄片。
  2. 热锅少油，爆香姜片和蒜瓣后下肉片快速翻炒。
  3. 加入豆瓣酱、生抽和少许糖，炒出红油后撒入青蒜段，再翻炒均匀后出锅。

梭子蟹炒年糕

⚖️材料配比

主料

  • 新鲜梭子蟹 1只（切块）
  • 年糕 200g（切片）

辅料

  • 姜丝、蒜末、葱适量
  • 干红椒少许
  • 生抽 1大勺、料酒 1小勺
  • 盐和糖适量

🔪庖厨之术

  1. 将蟹清洗后切块，年糕切片备用。
  2. 热锅放油，煸炒姜丝和蒜末后加入蟹块翻炒至表面微熟，倒入料酒去腥，加水煮开。
  3. 加入年糕片，淋入生抽，加入红辣椒干，调入少量糖和盐，快速翻炒均匀。
  4. 最后加入葱花，略炒后即可装盘。

鲜椒碎牛肉

⚖️材料配比

主料

  • 牛肉 300g（切丝）

辅料

  • 小红椒 2-3个（切碎）
  • 姜蒜末适量
  • 生抽 1小勺、料酒 1小勺
  • 淀粉和盐适量

🔪庖厨之术

  1. 将牛肉丝用生抽、料酒和淀粉腌制10分钟。
  2. 热锅放油，爆香姜蒜末后迅速下入牛肉丝翻炒至变色。
  3. 加入切碎的小红椒，快速翻炒均匀后调味出锅。

水煮牛肉

⚖️材料配比

主料

  • 牛肉片 300g（切薄片）
  • 豆芽或白菜适量

辅料

  • 姜片、蒜片适量
  • 豆瓣酱 1大勺、料酒 1小勺
  • 生抽少许、淀粉适量
  • 清汤或水适量

🔪庖厨之术

  1. 将牛肉片用生抽、料酒和淀粉腌制10分钟。
  2. 先将豆芽或白菜焯水备用，铺于碗底。
  3. 热锅放油，爆香姜蒜片后加入豆瓣酱炒出红油，倒入清汤煮开。
  4. 放入牛肉片，小火煮至全熟后，将汤汁连同牛肉倒在蔬菜上即可。

椒麻鸡

⚖️材料配比

主料

  • 鸡腿肉 500g（去骨切块）

辅料

  • 姜片、蒜末适量
  • 生抽 1大勺、白糖 1小勺、陈醋 1小勺
  • 花椒油适量
  • 芝麻和香菜少许

🔪庖厨之术

  1. 将鸡肉块用生抽、白糖和陈醋腌制30分钟。
  2. 热锅放油，下姜片和蒜末爆香后加入鸡块煎至两面金黄。
  3. 起锅前淋上花椒油，撒上芝麻和香菜后翻匀出锅。

东坡肉

烹饪时间：40分钟 炖煮时间：3小时

⚖️材料配比

主料

  • 常皮五花肉 800g
  • 绍兴黄酒 500ml

灵魂调料

  • 冰糖 50g
  • 小葱 2根

🔪庖厨之术

  1. 将肉块洗净、去毛整形，在表面划上井字花刀，并用细绳绑紧。
  2. 将整块五花肉放入开水中焯烫，捞出后用冷水冲洗备用。
  3. 在砂锅中放入肉块、绍兴黄酒、冰糖和小葱，大火煮开后转小火炖煮约3小时，期间翻面一次。
  4. 待肉质酥软、汤汁浓稠后关火，静置几分钟后切块装盘。

📌提示：用原味代替酱油，酒香更清淡。

醋蒸鸡

⚖️材料配比

主料

  • 鸡块 500g

辅料

  • 姜丝、葱段适量
  • 生抽 1大勺、香醋 1大勺、料酒适量

🔪庖厨之术

  1. 将鸡块洗净后用料酒和生抽腌制15分钟。
  2. 在鸡块表面铺上姜丝和葱段，并均匀淋上香醋。
  3. 将鸡块放入蒸锅中，水开后蒸15-20分钟至全熟。
  4. 出锅后撒上香菜装饰，即可上桌。

香肠饭

⚖️材料配比

主料

  • 中短粒米饭 2碗
  • 中式香肠 2根（切片）

辅料

  • 胡萝卜丁、青豆适量
  • 葱花、盐、生抽适量

🔪庖厨之术

  1. 热锅中放少许油，加入香肠煸炒出香味和油脂。
  2. 加入胡萝卜丁和青豆翻炒至略微软化。
  3. 加入米饭，用生抽和盐调味，翻炒均匀，使米饭吸收香肠油脂。
  4. 出锅前撒上葱花即可。

醋炒蛋

⚖️材料配比

主料

  • 鸡蛋 3个

辅料

  • 香醋 1小勺
  • 盐、葱花适量

🔪庖厨之术

  1. 将鸡蛋打散，加入盐调味备用。
  2. 热锅中倒入油，倒入蛋液待稍凝固时迅速淋入香醋。
  3. 快速翻炒，直至蛋液均匀散开且全熟，最后撒上葱花即可。

小炒香干

⚖️材料配比

主料

  • 香干 200g
  • 猪前腿肉 100g
  • 肥肉 100g

辅料

  • 青红线椒 200g
  • 葱花、蒜粒适量
  • 盐、鸡精、十三香

🔪庖厨之术

  1. 香干切片，青红椒对半开切小段。
  2. 水开加盐，倒入香干，焯水15秒，捞出备用
  3. 锅烧热后下肥肉，煎至半卷半脆后下蒜粒煸炒出香味
  4. 加入猪前腿肉，炒至半生不熟后加入酱油水上色
  5. 加入盐，鸡精，十三香，一点生抽，最后放入青红椒，全程大火炒至断生即可出锅

虫草花炖鸡汤

⚖️材料配比

主料

  • 整鸡或鸡腿 500g

辅料

  • 虫草花 10克
  • 姜片、料酒适量
  • 盐、葱花适量

🔪庖厨之术

  1. 将鸡肉洗净切块，焯水去腥备用。
  2. 在砂锅中放入鸡块、虫草花、姜片和料酒，加足水煮开后转小火炖煮1.5至2小时。
  3. 出锅前加入盐调味，撒上葱花装饰即可。

海带排骨汤

⚖️材料配比

主料

  • 猪排骨 500g

辅料

  • 海带 100g（泡发后切段）
  • 姜片、料酒适量
  • 盐、葱花适量

🔪庖厨之术

  1. 将排骨焯水后洗净，与姜片和料酒一起放入炖锅，加足水炖煮约1.5小时。
  2. 加入海带段继续炖煮20-30分钟，最后加入盐调味。
  3. 装盘前撒上葱花即可。

臊子面

⚖️材料配比

主料

  • 面条 200g

辅料

  • 猪肉末 150g
  • 西红柿 1个（切块）
  • 葱姜蒜末适量
  • 豆瓣酱 1小勺、生抽适量
  • 盐少许、香菜适量

🔪庖厨之术

  1. 将猪肉末用生抽和淀粉腌制10分钟。
  2. 热锅中放油，炒香葱姜蒜末后加入肉末翻炒。
  3. 加入豆瓣酱炒出红油，再加入西红柿块煮出汁。
  4. 加入煮熟的面条和适量盐，快速翻炒均匀后撒上香菜即可。

海鲜面

⚖️材料配比

主料

  • 面条 200g

辅料

  • 虾仁 100g、鱿鱼圈 100g、蛤蜊 200g
  • 蒜末、姜丝适量
  • 青菜适量
  • 生抽、盐、料酒适量

🔪庖厨之术

  1. 海鲜洗净后用少量料酒腌制去腥。
  2. 热锅放油，下蒜末和姜丝爆香，再加入蛤蜊煮至贝壳开口。
  3. 加入虾仁和鱿鱼圈快速翻炒，调入生抽和盐。
  4. 最后加入青菜翻炒至断生，将煮熟的面条与海鲜汤汁混合均匀后即可出锅。
